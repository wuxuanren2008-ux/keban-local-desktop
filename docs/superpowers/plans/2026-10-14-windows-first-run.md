**架构：** 使用新建 Windows runner 直接下载发布资产，核验 SHA256。在安装依赖前执行安装和免安装启动；测试进程 PATH 仅保留 Windows 系统目录，用户资料、模型缓存、临时目录使用测试专属路径，不依赖开发电脑的 Ollama、Python、Node 或模型。

**执行：** 使用当前工具逐项完成，不要求额外 superpowers 技能。保留失败日志、进程退出码、实际窗口与本机 API 检查证据。
