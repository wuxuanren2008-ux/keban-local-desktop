# 课伴 macOS 适配与原生验证计划

**Goal:** 提供 macOS 14+ 的 Apple Silicon 与 Intel 安装包，保留课堂、课程资料库、导图和课程纠错学习。

**Architecture:** Electron + 原生 Darwin Python 冻结服务，回环通信；faster-whisper CPU int8，Ollama 本机推理。分架构构建，Mac 专用麦克风用途声明与签名配置，不复制 Windows 二进制。

**Spec:** 本次用户请求，测试成功后创建单独 macOS GitHub 仓库。使用当前能力直接实施；用户已授权 WorkBuddy 分工。

## 文件边界
- Codex：desktop/main.cjs、model-setup.cjs、platform.cjs、package.json、frontend、测试驱动与 GitHub 工作流。
- WorkBuddy：build-macos.sh、requirements-macos.txt、entitlements.mac.plist、test_macos_runtime.py、macos-compatibility.md。

## 验收重点
- 正确使用 .venv/bin/python 与无 .exe 后缀的 Darwin 冻结服务。
- ARM / Intel 架构与依赖一致；打包后的服务、中文路径与可执行位有效。
- 本机模型下载、Whisper 识别、LLM 总结、SQLite/录音、导图与纠错记录在 macOS 上验证。
- Electron macOS 麦克风权限与关闭窗口 / Cmd+Q 生命周期不丢记录。
- 未签名/未公证状态真实说明，不关闭系统安全机制。
